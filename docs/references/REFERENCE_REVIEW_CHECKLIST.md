# Reference review checklist

- [ ] Image has a stable ID and SHA-256.
- [ ] Source and ownership are recorded.
- [ ] Mapped screen IDs are correct.
- [ ] Useful hierarchy and interaction traits are written down.
- [ ] Prohibited copying is explicit.
- [ ] Accessibility is not weakened.
- [ ] Functional requirements still come from the specs.
- [ ] A visual regression or native inspection target was updated.
- [ ] The manifest validates.
