# Out of scope for first release

- cloud project storage and collaboration
- public share links
- mobile recording or editing
- livestreaming
- generic plugin marketplace
- non-Codex AI providers
- API-key-first AI setup
- automatic paid asset purchasing
- remote stock search without explicit future design
- generative video
- full professional colour grading
- unrestricted node graphs
- arbitrary third-party code in the renderer
- unlimited free-form tracks
- live multi-user editing
- claims of macOS support before native acceptance

An out-of-scope feature may have an interface seam. It must not appear as an enabled control.
