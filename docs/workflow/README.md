# Implementation workflow

`active-phase.md` identifies the current dependency-safe phase. Detailed phase prompts, truthful in-progress notes, and accepted result records live in the neighboring `phases/`, `progress/`, and `results/` directories. Accepted records are validated against `docs/schemas/phase_result.schema.json`.

Generated and private material does not belong in this documentation tree. Test and native-run evidence stays under ignored `test-results/`; user media locators and other machine-local inputs stay under ignored `local-data/`.
