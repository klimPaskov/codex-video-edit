# Privacy checklist

- [ ] Recording sources are chosen explicitly.
- [ ] Screen, microphone, system audio, camera, and pointer permissions are separate.
- [ ] Keystrokes and clipboard are not captured.
- [ ] Source media remains local and immutable.
- [ ] Codex context disclosure is shown before first use.
- [ ] Raw full-resolution media is not sent to Codex by default.
- [ ] Logs redact paths, tokens, account details, and transcript text where required.
- [ ] Diagnostics export requires user action.
- [ ] Local assets include licence metadata.
- [ ] Project deletion is deliberate and does not imply source deletion.
- [ ] Crash reports are opt-in or local for the first release.
