# Phase checklist

- [ ] Read authoritative sources and relevant skills.
- [ ] Identify the first incomplete dependency-safe phase and exact task IDs.
- [ ] Inspect existing implementation and baseline tests.
- [ ] Research current contracts when versions or APIs may have changed.
- [ ] Add or update tests.
- [ ] Implement the smallest complete slice.
- [ ] Validate schemas and examples.
- [ ] Run deterministic media checks when media changes.
- [ ] Launch the native app in the isolated environment when UI changes.
- [ ] Run Playwright Electron and visible computer-use review.
- [ ] Review privacy, security, licences, and source immutability.
- [ ] Run spec-sync and update traceability.
- [ ] Write `.astra/results/PHASE_ID.json`.
- [ ] Mark tasks only after evidence exists.
