# Native UI review checklist

- [ ] App opens in its own desktop window.
- [ ] No normal browser tab or localhost product surface appears.
- [ ] Only the current step is prominent.
- [ ] One primary action is clear.
- [ ] No more than one inspector is open.
- [ ] Empty tracks and unavailable tools are hidden.
- [ ] Logs and protocol events are hidden outside Diagnostics.
- [ ] Text, controls, focus, and contrast remain readable at supported scaling.
- [ ] Keyboard navigation and shortcuts work.
- [ ] Drag, trim, canvas handles, and selection states are clear.
- [ ] Loading can be stopped safely.
- [ ] Errors keep completed work visible.
- [ ] Codex activity is brief and understandable.
- [ ] Screenshots and a short native recording are saved.

- [ ] Current and previous references are distinguishable and individually viewable.
- [ ] Mandatory screenshot corrections have been applied.
- [ ] No Ready status in the bottom-left corner, hero headings, or obvious instructional subtitle.
- [ ] Codex edits update real draft state while a turn runs.
- [ ] Only the relevant inspector or drawer is open by default.
