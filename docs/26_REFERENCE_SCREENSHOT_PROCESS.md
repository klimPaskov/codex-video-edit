# Reference integration

The workspace includes ten current and ten previous individual native-app reference images. Begin with `references/README.md`, `references/IMPLEMENTATION_NOTES.md`, and `references/SCREEN_COVERAGE.md`.

For every screen change:

1. Read the mapped full-resolution reference and authoritative behavior spec.
2. Apply the latest simplicity, lossless, live-Codex, and native-window requirements.
3. Build functioning components from the domain model, not a screenshot background.
4. Add interaction and accessibility tests.
5. Launch the real app in the isolated desktop environment.
6. Inspect its screenshot and output. Compare hierarchy and density as well as control behavior.
7. Update the manifest, mapped specification, task, and skill when the workflow changes.

The image files remain unmodified reference originals. Generated reference images do not prove native launch, successful export, licensing, or test results. No contact sheets replace individual references.
