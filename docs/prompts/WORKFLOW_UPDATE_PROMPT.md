# Workflow update prompt

A workflow contract changed. Apply the change consistently.

1. Identify the exact source requirement and affected phases.
2. Update the feature spec and user flow.
3. Update affected screen specs and error states.
4. Update domain schemas, examples, migrations, and tool contracts.
5. Update task dependencies and acceptance evidence.
6. Update unit, integration, media, Playwright Electron, and computer-use checks.
7. Update skills and subagent routing.
8. Update traceability and reference manifest.
9. Run package and repository validation.
10. Record what changed and what remains unsupported.

Do not leave old instructions active in another file. Do not claim a workflow is updated when only the UI text changed.
