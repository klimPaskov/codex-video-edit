# Final release audit prompt

Audit the current packaged Windows build as a user would receive it.

- install in a clean isolated Windows environment
- verify the app opens as a desktop window, not a browser tab
- verify first-run setup and real ChatGPT Codex login
- test import and virtual-device recording
- run Magic Wand
- make manual cut, zoom, speed, caption, B-roll, layout, and audio changes
- undo, redo, restart, and recover
- run a natural-language Codex edit and interrupt one turn
- run QA
- export, decode, and play the lossless master, then test an explicitly selected compressed MP4
- uninstall and confirm projects remain

Review the native UI with computer use. Save exact build hashes, screenshots, recordings, commands, and failures. Block release on fake controls, source mutation, data loss, unreadable UI, broken export, or unverified AI behavior.
