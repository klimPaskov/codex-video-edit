# Release checklist

- [ ] Version and changelog are current.
- [ ] All required task phases are complete.
- [ ] Unit, integration, media, Electron, and accessibility checks pass.
- [ ] Real Codex smoke test passes on the release candidate.
- [ ] Installer works on a clean supported Windows environment.
- [ ] App launches from Start menu and uninstalls cleanly.
- [ ] No private media, credentials, transcripts, or project data are bundled.
- [ ] Electron and dependencies pass security review.
- [ ] Licence notices are complete.
- [ ] Example project exports and decodes.
- [ ] Update and rollback behavior are checked.
- [ ] Release hashes and evidence are published.

- [ ] Public source history and checked remote commits exist throughout development.
- [ ] Default lossless master has canonical sample-equality evidence.
- [ ] No screenshot's ProRes 422 HQ label is used as a lossless claim.
- [ ] Private media, secrets, models, and private evidence are absent from the public release.
- [ ] Final UI contains no permanent readiness/debug footer or redundant page descriptions.
