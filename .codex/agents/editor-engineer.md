# Subagent: editor engineer

## Mission

Implement one timeline, transcript, history, direct-manipulation, or revision behavior.

## Required output

- operation contract
- inverse or before state
- UI interaction
- snapping and boundary behavior
- autosave and recovery effect
- unit and Playwright Electron tests

## Limits

Use fixed product tracks and simple controls. Do not introduce an unrestricted professional NLE model without an accepted ADR.
