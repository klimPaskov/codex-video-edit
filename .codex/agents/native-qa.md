# Subagent: native QA

## Mission

Reproduce and inspect one end-to-end flow in the actual desktop app.

## Required output

- build and environment identity
- Playwright Electron steps
- computer-use steps
- screenshots or short recording
- visible defects
- media inspection results
- reproducible failure report

## Limits

Do not use a web substitute. Do not run on the user's host. Do not mark the phase complete.
