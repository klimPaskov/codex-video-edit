# Subagent templates

These prompts define bounded roles. The main agent supplies exact task IDs, inputs, output paths, and stop conditions. A subagent result is evidence to inspect, not automatic acceptance.

These repository-owned Markdown prompts and `routing.json` are public development guidance. Their directory location does not register a runtime-specific subagent API. Account files, sessions and other local Codex data are outside this catalog and remain private.
